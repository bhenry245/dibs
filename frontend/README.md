# Dibs frontend

React + TypeScript single-page app, built with Vite and styled with Tailwind CSS.

Setup, run and test instructions are in the [root README](../README.md#running-locally).

| Command | Does |
|---|---|
| `npm run dev` | Dev server on http://localhost:5173, proxies `/api/*` to the API on :8000 |
| `npm run lint` | Lint with oxlint |
| `npm run build` | Type-check, then build static files into `dist/` |
| `npm test` | Run tests with Vitest |
